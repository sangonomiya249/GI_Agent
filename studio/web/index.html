一条龙要添加哪些调度器

名字必须与 User\ScriptGroup\<名字>.json 完全一致
调度器 = BetterGI 里的「脚本组」：把脚本仓库里的路径追踪目录 / JS 脚本加进一个组， 给它起名，然后在「一条龙」界面把它添加进去。组名就是一条龙任务名， BetterGI 运行时按这个名字去取 User\ScriptGroup\<名字>.json。

一、在 BetterGI 里配置一条龙

  1. 装好 BetterGI 并至少手动跑过一次：它会生成 User\config.json、User\OneDragon\*.json、User\AutoPathing。
  2. 建调度器（脚本组）：进入「调度器」，把脚本仓库里对应的目录加进一个组：
    • pathing/地方特产 → 组名 地图素材（建议全选，不用怕路线重叠）
    • pathing/敌人与魔物 → 组名 敌人与魔物（整组 1000+ 条也行，Agent 会按目标自动精简）
    • pathing/锄地专区 → 组名 锄大地（缺失时 Agent 会按 User\AutoPathing\锄地专区 自动生成）
    • pathing/矿物、pathing/食材与炼金 → 组名 矿物、食材与炼金（也可以按材料建小组，如 石珀 / 虹滴晶）
    • JS 脚本 批量讨伐角色养成材料BOSS、狗粮AAA（AAA 狗粮批发）→ 各自建成同名组
  3. 加进一条龙：在「一条龙」界面把这些组添加进任务列表并勾选一次。 Agent 之后会自动开关它们（未登记的组它也会自动补登记）。
  4. 组内设置检查：战斗策略建议用「根据队伍自动选择」，或确保策略 txt 真的在 User\AutoFight\ 下（体检里会列出对不上的组）。
  5. 计划任务（可选但强烈建议）：以管理员身份运行一次 scripts\setup_start_bettergi_task.ps1，见下方 PowerShell 说明。
Agent 会改的东西：一条龙配置里的 TaskEnabledList / TaskOrder（按任务 Id）、 脚本组里的路线 status、刷本次数写进 User\config.json → autoDomainConfig、 Boss 列表写进脚本的 assets\config\config.json。 所有写入都有备份与 Diff，可用 rollback <事务ID> 还原。

二、配置这个软件（.env）

LLM 模型LLM_PROVIDER（openai / github / nvidia / custom / local）+ MODEL_NAME
模型密钥OPENAI_API_KEY（或对应提供商的 key）
接口地址OPENAI_BASE_URL：走 DeepSeek 就填 https://api.deepseek.com/v1
你的 UIDDEFAULT_UID（展柜数据按它抓取）
BetterGI 路径BGI_DIR（默认 C:\Program Files\BetterGI）
脚本组名BGI_MAP_CONFIG_NAME / BGI_ENEMY_CONFIG_NAME / BGI_HOE_CONFIG_NAME / BGI_MINE_CONFIG_NAME / BGI_COOK_CONFIG_NAME
路线组策略BGI_ROUTE_GROUP_POLICY（默认 shrink：大组自动精简+归档）、BGI_MAX_ROUTE_GROUP_SIZE
JS 脚本设置BGI_JS_SCRIPT_SETTINGS：默认关掉 Boss 脚本启动时的配置编辑器
刷本树脂DOMAIN_RESIN_PREFERENCE（原粹树脂20 / 原粹树脂40 / 浓缩树脂）
飞书（可选）FEISHU_APP_ID / FEISHU_APP_SECRET / FEISHU_VERIFICATION_TOKEN
QQ 机器人（可选）QQ_BOT_APPID / QQ_BOT_SECRET / QQ_BOT_ALLOWED_USERS（+ QQ_BOT_ALLOW_ANYONE 危险开关）
直接在左边「配置」页里改，保存会自动备份成 .env.bak-时间戳； 改完要「■ 停止」再「▶ 启动」才生效（配置在进程启动时读取）。 运行环境换机器时，至少要改：BGI_DIR、DEFAULT_UID、LLM 密钥。

三、PowerShell 配置项（免 UAC 启动 / 关闭 BetterGI / 关闭原神）

注册脚本以管理员身份跑一次就够
为什么要它们：BetterGI 和原神通常都是以管理员权限运行的，而 Agent 在普通权限终端/机器人里跑 —— 直接 taskkill 会 Access denied（原神就是这句「拒绝访问」），直接启动 BetterGI 会弹 UAC； 而且 BetterGI 是单实例程序，热启动不会触发新的一条龙，必须先关掉再冷启动。 所以用三个「最高权限」的计划任务代劳：StartBetterGI / StopBetterGI / StopGenshin。
⚠️ 管理员 PowerShell 打开时默认在 C:\WINDOWS\system32，所以上面命令里的路径是完整路径， 直接复制粘贴即可；写成相对路径会报「实际参数…不存在」。
状态文件：scripts\stop_bettergi.pids/.log（关 BGI 的目标与记录）、 scripts\stop_genshin.pids/.log（关原神的目标与记录）。 两个关闭脚本都只按 PID 文件精确关闭，并且校验进程名白名单，绝不按进程名乱杀。

三·五、远程遥控（可选：QQ / 飞书）

让 Agent 在手机上听你指挥
在哪儿启停左侧「远程通道」页：每个通道一张卡，▶ 启动 / ■ 停止 / 清空日志，日志直接内嵌在下面（不用再开黑色控制台窗口）
随 Agent 自动启动点右上角「启动 Agent」时，已填好配置且勾了「随 Agent 自动启动」的通道会被一起唤醒；点「停止」或关窗口时一起关。开关存在 AUTO_START_QQ_BOT（默认 1）/ AUTO_START_FEISHU_BOT（默认 0）
QQ 通道（轻量，不用装机器人框架）在 q.qq.com 建一个机器人 → 把 AppID / AppSecret 填进「配置 → QQ 机器人」→ 回「远程通道」页点启动（或双击 启动QQ机器人.bat 单独跑）
只认你自己QQ_BOT_ALLOWED_USERS 填你的 openid。留空时机器人会拒收所有指令，并把你的 openid 回给你 —— 先随便发一句抄进去再重启即可
在 QQ 里怎么用群里 @机器人 或私聊发一句话（如「今天体力怎么花」）→ 出审批屏 → 点按钮 ✅ 执行 / 🧪 仅改配置 / 🚫 取消（等价回复 y / t / 取消），也可直接打字；refresh 刷展柜、clear 清记忆。手机上默认只发精简审批屏（QQ_BOT_REPLY_MODE=compact），完整推理在电脑端日志里；设成 off 就是单向模式：QQ 只用来下指令，Agent 的回话（连审批屏也是）全部只显示在本机日志里，审批在电脑上做
拿不到按钮权限？消息按钮要平台【内邀开通】/【申请使用】；单聊底部自定义菜单不需要，跑一次 python main.py qq --setup-menu 就有「✅ 执行 / 🧪 测试 / 🚫 取消」
飞书通道Webhook 模式，需要内网穿透 + 飞书开放平台配置。默认不随 Agent 启动（公网不可达时收不到消息，白占一个进程），需要就把 AUTO_START_FEISHU_BOT 设成 1；FEISHU_REPLY_MODE=off 同样是单向模式（只收指令不回话）
两条通道共用同一套逻辑（规划 / 审批 / 配置事务 / 回滚提示），回复靠 target 前缀自动分发， 细节见 docs/QQ_BOT.md。⚠️ 官方限制：QQ 的被动回复凭据只有 5 分钟有效期 —— 审批屏发出后超过 5 分钟才回 y，回执会发不出去（重新发一句话就会开一段新的凭据）。

五、排错速查

战斗策略文件不存在组里配的策略名在 User\AutoFight 下没有对应 txt → 改成「根据队伍自动选择」，或把 txt 复制进去。体检会列出是哪几个组。
当前获取焦点的窗口不是原神跑图时切了窗口，BetterGI 会暂停甚至中止 → 挂机时别动键鼠；把 showStatusPanel 关掉也能少一个抢焦点的悬浮窗。
停止任务时 BetterGI 闪退（0xc00000fd）组里躺着大量 Disabled 路线导致日志爆发 → 保持 BGI_ROUTE_GROUP_POLICY=shrink（自动精简+归档）。
说「刷点XX」没反应那个类目没有脚本组，或组没登记进一条龙 → 看「任务与路线」页，或跑一次体检。
讨伐前弹一个要手点"保存并关闭"的窗口脚本自带的 BOSS 配置编辑器 → Agent 已把 showEditorOnStart=false 写进脚本组；想手动编辑就在 BetterGI 里右键脚本 →「修改JS脚本自定义配置」勾回来。
一条龙列表多了奇怪的任务（如 AutoBoss）历史遗留的空转任务 → 关掉 BetterGI 后跑 python main.py repair 摘掉它。
展柜里查不到某个角色先点「概览 → 刷新展柜」；还不行检查 DEFAULT_UID 与该角色是否真的在游戏展柜里。
Agent 说无法关闭 BetterGI说明 StopBetterGI 计划任务没注册 → 以管理员身份跑一次 setup_start_bettergi_task.ps1，或手动关掉 BetterGI 再试。
QQ 里 @了机器人没反应① 没申请「群聊/单聊消息」权限（intents 里的 1<<25）；② 白名单要填 openid 而不是 QQ 号 —— 机器人会把你的 openid 回给你，抄进 QQ_BOT_ALLOWED_USERS 再重启；③ 先跑 python main.py qq --check（会一路验到网关握手）。
日志刷 取网关失败：HTTP 426取网关地址的路径不对（老版本问题，已修）：官方 v2 是 GET /gateway，/websocket/ 是 WebSocket 入口本身，普通 GET 会被网关挡回来。现在会自动改走直连 wss://api.sgroup.qq.com/websocket，不影响使用。
QQ 机器人回一句就再没下文被动回复凭据 5 分钟过期（官方限制）→ 重新发一句话；长回复会自动分段并按 msg_seq 递增发送。
QQ 审批屏没有按钮 / 点了转圈按钮要在 QQ 开放平台开通（自定义按钮=内邀开通，模板按钮=申请使用），没开通会提示一次并自动退回纯文本；点了转圈说明 intents 少了互动事件位 1<<26（把 QQ_BOT_INTENTS 清空用默认值即可）。

GI Agent Studio

桌面程序：GI-Agent-Studio.exe 是原生窗口（WinForms + WebView2 控件）， 不是浏览器窗口 —— 没有地址栏/标签页，任务栏里就是它自己；关掉窗口时后端会一起退出。 界面与后端（本地 Flask，只监听 127.0.0.1）都随 exe 启动， 它不重写 Agent 逻辑 —— main.py 仍是唯一的执行体， Studio 只负责启动/停止/看日志/改配置。

旧版 tkinter 控制台仍保留为备用：启动GI-Agent控制台.bat 或 python main.py gui。 如果 WebView2 起不来，exe 会自动退回"浏览器应用窗口"模式（功能一样），细节见 studio-host.log。
