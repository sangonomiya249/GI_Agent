# 使用说明

进入对话模式后，Agent 会先读一次你的角色展柜，并给出今天的规划建议。
之后就可以像指挥一个真人代肝一样跟它说话。

---

## 审批：`y` / `t` / 其它

Agent 每次要动 BetterGI 配置时都会先出一份计划，等你拍板：

| 回复 | 效果 |
| --- | --- |
| `y` | 写配置 **并** 拉起一条龙 |
| `t` | **只写配置**，不启动游戏（推荐前几次都用它） |
| 其它内容 | 当作驳回，Agent 会按你的新要求重新规划 |

建议一开始都用 `t` 跑，在 BetterGI 里确认配置改对了，再开始用 `y` 挂机。

## 各种说法对应哪类任务

### 消耗体力

* `去刷蓝砚的天赋` / `去打一次蓝砚武器的突破副本` —— 说角色名就行：Agent 从展柜读 TA **当前携带的武器**，
  自动换算成对应炼武秘境并补上 `domain_index`，不需要你报秘境名。
  * 审批时会顺带提示**这个秘境今天开不开**（例如「凛风奔狼系只在 周二/五/日 掉落，今天是周四」）——只是提醒，你确认要做照样执行。
  * **说「打一次 / 打 N 次」才会限次**：次数写进 BetterGI 的 `User/config.json → autoDomainConfig`。
    **不说次数就是刷到体力耗尽**（这是 BetterGI 自己的默认行为）。用哪种树脂看 `.env` 的 `DOMAIN_RESIN_PREFERENCE`（默认 `原粹树脂20`）。
* `去打一次散兵的突破材料` —— 走《批量讨伐角色养成材料BOSS》：角色名 → 突破材料 → 首领，
  **不会按元素属性瞎猜**（猜错就是白跑一趟）。打几次说清楚，默认 100 次。
* `去刷地脉` / `刷点摩拉` —— 自动地脉花。藏金之花记摩拉、启示之花记经验书，会记进虚拟账本。
* `去刷草套` / `去刷绝缘套` / `去刷猎人套` —— 圣遗物。**Agent 不会根据角色推导圣遗物**，
  你得明确说套装；支持常用简称（尽量以「套」结尾）。

### 大世界

* `去采集霜仙花` —— 地区特产有 **48 小时冷却**，采过没刷新会告诉你还要等多久（详见 README 的采集物冷却一节）。
  ⚠️ 材料名要写对：名字错了对应路线不会被激活。
* `去采集奥黛塔的普通突破材料` —— 说角色名也行，Agent 先解析成 TA 的采集物材料再查冷却；
  认不出来的新角色会老实说"认不出，请直接说材料名"，绝不猜一个材料去排。
* `去刷点蕈兽` / `刷点原素花蜜` / `缺刀镡` —— 刷怪。敌人名或它的**掉落材料**都行。
* `去挖点水晶块` / `挖紫晶块` / `打点星银矿石` —— 挖矿（`矿物` 组）。你自己按材料分好的小组（`石珀`、`虹滴晶`）会被直接认出来用。
* `刷点禽肉` / `采点薄荷` / `打些鱼肉` —— 食材与炼金材料。
* `锄大地` / `锄地` / `清怪` / `扫图` / `刷精英` / `打传奇` —— 按地区扫图；`锄大地 璃月` 只清璃月。
  ⚠️ 别和刷怪混：**具体魔物**（`刷点骗骗花`）只打那个魔物的固定怪点，**范围清怪**（`锄大地`）才按地区扫图。
  两者的区别与路线隔离见 [BetterGI 准备清单](BETTERGI_SETUP.md#锄大地和敌人与魔物不一样)。
* `去跑狗粮` / `跑一下采集水下` / `跑一下锄地一条龙` —— 这类不是跑图路线，而是**整个 JS 脚本**挂在调度器组里跑。
  审批屏会写明命中了哪个脚本组、组有没有登记进一条龙。

> 类目写错会自动改判：模型把「久雨莲」（食材与炼金）当成特产写成 `gather` 时，系统会核对各类目里到底有没有这条路线，
> 改判到正确类目并在审批屏提示 `🔄 …已改判为…`；把敌人路线当成 Boss 写成 `run_boss` 也会被改判成 `hunt`。
> 反过来，真首领（如「秘源机兵构型械」，敌人组里也有相近的「秘源机兵」杂兵路线）不会被抢走。

### 系统操作

* `帮我关闭原神` —— 出计划 → 回 `y` → 先正常关闭，没退再强制结束（进度在服务器上，强杀不丢档）。
  想连 BetterGI 一起关就说 `帮我关闭原神和 BGI`。
* `退出` / `exit` / `quit` —— 结束终端会话（记忆会保存）。

**关闭原神的安全边界**（为什么它不会乱关）：

| | |
| --- | --- |
| 先礼后兵 | 先 `taskkill /PID`（等于点窗口右上角的叉）→ 等 `GAME_CLOSE_GRACE_SECONDS`（默认 10 秒）→ 还没退才强制结束 |
| 只按白名单 | 只认 `YuanShen.exe` / `GenshinImpact.exe` / BetterGI 配置里的启动程序名；**不按窗口标题通配、不按父子关系杀** |
| 连 BGI 一起关 | 你明确说了才关；没说时只有检测到 BetterGI **正在跑任务**才捎带（并在审批屏写明原因） |
| 不会被误触发 | 「别关原神」（否定）、「原神关了吗」（疑问）、「关掉游戏声音/画质/全屏」（游戏内设置）都不会关 |
| 结果如实报 | 关掉了 / 强杀了 / 没关掉 / **还是判不出来**，都照原话说（判不出来时绝不说"已关闭"） |
| 权限不够也能关 | 原神常以管理员权限运行，普通终端会被「拒绝访问」。这时自动改走同等权限的计划任务 `StopGenshin`（免 UAC）；任务没注册会告诉你跑哪条命令，见 [排错 FAQ](TROUBLESHOOTING.md#关原神与关-bettergi-的权限问题) |

命令行也能用（默认只体检，`--close` 才真关）：

```bash
python -m skills.game_control            # 看计划：在不在跑、会怎么关
python -m skills.game_control --close    # 真关原神
python -m skills.game_control --close --with-bgi   # 连 BetterGI 一起关
```

### 其它对话

* 系统默认保留 `20` 条上下文（`MAX_HISTORY_MESSAGES`），额度充裕可以调高；
* 也可以聊原神无关的话题，这里不限制你的想象力 🐶。

## 展柜数据

Agent 每次启动都会重新拉取展柜（Enka）并把**抓取时间**写进上下文；飞书/QQ 模式下缓存超过
`ENV_CONTEXT_TTL_MINUTES`（默认 10 分钟）也会自动重拉。

会话中想立刻刷新（刚换过展柜，或 Agent 说「某角色不在展柜 JSON 中」），在 CLI 里输入：

```text
refresh
```

展柜里每个角色的 `materials` 分四类：

| `type` | 怎么刷 | 关键字段 |
| --- | --- | --- |
| `特产` | 大世界采集（`gather`） | `schedule` = 采集地点 |
| `秘境材料` | 刷秘境（`run_domain`） | `schedule` = 秘境名 + 开放日程 |
| `Boss材料` | 首领讨伐（`run_boss`） | `needed` = 到 81 级还缺多少 |
| `敌人掉落` | 普通怪物掉落，讨伐大世界魔物（`hunt`） | `schedule` = `讨伐【魔物名】`、`total` = 满突破总需求（**≠ 当前缺口**） |

一次只能放 8 个角色。想查**展柜外**的角色，填一份米游社 cookie 即可（可选）：
[米游社 cookie 指南](MYS_COOKIE.md)。

## 配置恢复（`rollback`）

每次写 BetterGI 配置都会先备份、生成 Diff、原子替换、回读校验；失败会自动回滚本次事务。
如果配置写进去了但不符合预期，在 CLI 里输入：

```text
rollback            # 列出最近的事务，按提示选
rollback <事务ID>   # 直接还原指定事务
```

细节与事务目录结构见 [配置恢复](CONFIG_RECOVERY.md)。

## 常用命令速查

```bash
python main.py                      # 终端对话模式
python main.py doctor               # 环境体检（BetterGI 路径 / 计划任务 / 脚本组 / 展柜缓存）
python main.py repair [--force]     # 清理 Agent 留下的调度器开关与死键（走事务，可回滚）
python main.py qq [--check]         # QQ 机器人（--check 只验 AppID/Secret）
python main.py studio               # 打开 Studio
python main.py gui                  # 旧版 tkinter 控制台

python -m skills.gather_cooldown    # 采集物冷却（--check / --manual / --clear / --materials）
python -m skills.game_control       # 关闭原神（--close 才真关，可加 --with-bgi）
python -m skills.mys_api            # 米游社（--check / --refresh / --show 角色名）
python -m skills.window_focus       # 看游戏窗口 / 前台状态（--focus 才真抢焦点）
python -m skills.task_scheduler     # 三个计划任务在不在
```
